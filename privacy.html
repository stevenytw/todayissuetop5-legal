개인정보처리방침

본 방침은 유튜브 채널 투데이이슈(Today Issue Top5 / Top20)가 운영하는 자동 업로드 프로그램이 Google 계정 정보와 YouTube API 서비스를 어떻게, 그리고 왜 사용하는지 설명합니다.

Summary for reviewers

This app is a single-operator automation pipeline that publishes pre-produced, script-generated news-summary videos to one YouTube channel owned by the developer. It does not collect, view, or process any data belonging to end users or viewers.

The only Google data accessed is the developer's own OAuth grant, used solely to upload a video file and set its title, description, tags and thumbnail on the developer's own channel.

  • https://www.googleapis.com/auth/youtube.upload
01

서비스 개요

투데이이슈는 매일 두 차례(오전 6시 50분, 오후 6시 50분) 그날의 주요 뉴스를 요약한 카드뉴스·쇼츠·롱폼 영상을 자동으로 생성하여 Instagram, Facebook, YouTube에 게시하는 개인 운영 콘텐츠 파이프라인입니다.

이 문서가 대상으로 하는 프로그램(이하 "본 앱")은 그중 YouTube 업로드 단계를 담당하며, 렌더링이 끝난 영상 파일을 개발자 본인의 채널에 예약 비공개로 업로드하는 역할만 수행합니다.

02

수집하는 개인정보

수집하는 최종 사용자 개인정보 없음

본 앱은 시청자·구독자 등 최종 사용자로부터 어떠한 개인정보도 수집하지 않습니다. 회원가입, 로그인, 쿠키 기반 추적, 분석 SDK를 사용하지 않으며, 사용자를 대상으로 한 별도의 데이터베이스나 프로필도 운영하지 않습니다.

본 앱이 다루는 유일한 계정 정보는 개발자 본인이 Google OAuth 동의 화면을 통해 직접 부여한 접근 권한(refresh token) 하나뿐입니다.

03

Google 사용자 데이터 접근 및 사용 방식

본 앱은 아래 단일 범위(scope)만 요청합니다.

  • https://www.googleapis.com/auth/youtube.upload — 렌더링된 영상을 업로드하고, 제목·설명·태그·공개 예약 시각·썸네일을 설정하는 용도로만 사용됩니다.

이 권한으로 접근하는 대상은 개발자 본인이 소유한 채널이 유일하며, 다른 사용자의 채널·댓글·구독자 목록·분석 데이터 등은 조회하거나 수집하지 않습니다. 업로드된 영상의 공개 여부는 항상 "비공개"로 시작하여 지정된 시각에 자동으로 공개 전환되도록 예약되며, 이 전환 역시 YouTube 자체 기능(publishAt)을 통해 이루어집니다.

04

데이터 저장 및 보안

OAuth 클라이언트 ID·시크릿·refresh token은 GitHub Actions의 암호화된 Secrets 저장소에만 보관되며, 코드 저장소나 로그, 채팅 등 어디에도 평문으로 노출되지 않습니다. 이 값에 접근할 수 있는 주체는 저장소 관리자(개발자 본인)로 한정됩니다.

자동화 서버(GitHub Actions 러너)는 매 실행마다 새로 생성되고 종료되며, 영상 파일과 임시 자격 증명은 실행이 끝나면 함께 폐기됩니다.

05

제3자 제공

본 앱은 어떠한 개인정보도 제3자에게 판매, 대여, 공유, 양도하지 않습니다. 영상 렌더링 과정에서 Cloudinary(영상·이미지 임시 저장), Pexels·Unsplash (배경 소재)와 같은 외부 서비스를 이용하지만, 이들에 전달되는 데이터는 이미 완성된 콘텐츠 자산이며 최종 사용자의 개인정보가 아닙니다.

06

Google API 서비스 사용자 데이터 정책 준수

본 앱의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책을 준수하며, 이 중 제한적 사용(Limited Use) 요건을 포함합니다.

07

접근 권한 철회

개발자는 언제든지 Google 계정 → 보안 → 타사 앱 및 서비스 에서 본 앱의 연결을 해제할 수 있으며, 해제 즉시 저장된 refresh token은 무효화되어 더 이상 업로드에 사용될 수 없습니다.

08

정책 변경 및 문의
